# requirements-ml.txt — the ML library set, installed by setup/install-ml-windows.ps1
#
# NOTE: torch / torchvision / torchaudio are deliberately NOT listed here.
# They must come from PyTorch's own package index with a CUDA channel matched
# to the GPU (see install-ml-windows.ps1). Listing them here would let the
# resolver pull a generic wheel with no kernels for the card.
#
# Deliberately unpinned: this is a workstation environment, not a reproducible
# build. Pin per project (uv.lock / requirements.lock), not globally.
