WezTerm

Leader = Ctrl+a (then a key within 1s)

Panes split & move

  • CtrlShiftd/eSplit horizontal / vertical
  • Ldr|/-Split horizontal / vertical
  • CtrlShifth j k lFocus pane left/down/up/right
  • CtrlShift↵·LdrzZoom pane (toggle)
  • CtrlShiftx·LdrxClose pane
  • LdrpPick pane by letter
  • LdrrResize mode (hjkl, Esc exits)
  • CtrlShiftAltH J K LResize pane

Tabs

  • CtrlShifttNew tab
  • CtrlShiftw·LdrqClose tab
  • CtrlTab/CtrlShiftTabNext / prev tab
  • Alt1…9Jump to tab 1–9

Workspaces apps

  • LdrnNew named workspace
  • LdrwWorkspace switcher (fuzzy)
  • LdrTab·Ldr]Next workspace
  • LdrShiftTabPrevious workspace
  • CtrlShiftSpaceFuzzy switcher — apps/tabs/workspaces/commands

Scrollback & Search

  • Ldr↑/↓Jump to prev / next shell prompt
  • LdryCopy the last command's output
  • Ldr[Copy mode (vim motions)
  • CtrlShiftf·LdrfSearch scrollback
  • CtrlShiftPgUp/PgDnScroll half page

Select & Copy

  • LdrSpaceQuick-select — URLs, SHAs, IPs, paths, emails
  • LdroOpen a URL on screen in browser
  • LdreChar / emoji picker (copies)
  • CtrlShiftc/vCopy / paste · drag=copy, mid-click=paste

Window

  • Super←/→Snap left / right half (Ldrh/l)
  • Super↑/↓Maximize / restore
  • Ldrm/cMaximize / center
  • Super↵·F11·LdrShiftFFullscreen
  • Superh·Ldr,Minimize
  • LdrbToggle tab bar
  • LdrShiftOToggle transparency

Launch

  • CtrlShiftpProfile launcher
  • CtrlShiftzZellij in a new tab
  • CtrlShiftAltPCommand palette
  • LdruAttach persistent mux session (wtp)
  • Ldr?This cheatsheet (in-terminal)
  • Ctrl=/-/0Font bigger / smaller / reset

Session resurrect

  • LdrShiftSSave current layout to disk
  • LdrShiftRRestore a saved layout (fuzzy picker)
  • autoAutosaves every 5 min + whenever a window loses focus/closes
