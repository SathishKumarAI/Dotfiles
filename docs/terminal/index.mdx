## The stack

- **wezterm** is the emulator (window, GPU rendering, fonts, tabs/panes).
- **zellij** is the primary multiplexer for persistent, layout-driven sessions.
- **tmux** is kept as a fallback (e.g. on remote hosts) with a matching
  `Ctrl+a` prefix and vim navigation so muscle memory carries over.

Both multiplexers use **`Ctrl+a`** as prefix (not the default `Ctrl+b`) to avoid
clashing with vim's `Ctrl+b` page-up.
