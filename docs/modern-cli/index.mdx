# Modern CLI Tools

**Intro.** A set of fast, `.gitignore`-aware, syntax-highlighted replacements for
the classic Unix tools. The shell configs **already reference** them (zsh aliases
`ls→eza`, `cat→bat`; fzf uses fd + bat preview), and they're now **installed and
active** on this host. This page covers what each does and how to use it.

> Status on this host: `fzf` ✅ `rg` ✅ `fd` ✅ `bat` ✅ `eza` ✅ `delta` ✅
> (zsh aliases them automatically; **delta is now wired as the git pager** —
> see [git-config](../git/git-config.mdx)).

## Why these (what each replaces, and why)

| Tool | Replaces | Why chosen |
|------|----------|-----------|
| **ripgrep** (`rg`) | grep | Orders of magnitude faster; respects `.gitignore` (skips `node_modules`/build dirs) by default |
| **fd** | find | Simple syntax, smart-case, `.gitignore`-aware; powers fzf's file search |
| **bat** | cat | Syntax highlighting + line numbers + git gutter; **plain when piped** so scripts are unaffected |
| **eza** | ls | Icons, git status, `--tree`; the **maintained successor to the deprecated `exa`** |
| **delta** | diff/pager | Syntax-highlighted, side-by-side git diffs; pairs with git + lazygit |
| **fzf** | (new) | Interactive fuzzy finder — the glue for `Ctrl-T`/`Ctrl-R`/`Alt-C` and `zellij-pick` |

**Why "safer":** ripgrep/fd respecting `.gitignore` means searches don't wander
into secrets/build junk; bat staying plain in pipes avoids corrupting scripted
output. These are the consensus 2026 modern-CLI baseline
([linuxteck](https://www.linuxteck.com/modern-linux-tools/)).

## Install / enable

Installer: **`setup/install-modern-cli.sh`** — **distro-aware** (dnf on
Rocky/Fedora, pacman on Arch, apt on Debian/Ubuntu) with a `cargo install` /
prebuilt-binary fallback for whatever isn't packaged, then verifies each binary.

```bash
sudo bash setup/install-modern-cli.sh
# under the hood it picks the right manager, e.g.:
#   Rocky:  sudo dnf install -y ripgrep fd-find bat fzf ; cargo install eza git-delta
#   Arch:   sudo pacman -S ripgrep fd bat fzf eza git-delta
```

After install, the existing zsh aliases activate automatically (they're guarded
by `command -v`). delta is **already wired** in `chezmoi/dot_gitconfig`:

```ini
[core]
    pager = delta
[interactive]
    diffFilter = delta --color-only
[delta]
    navigate = true        ; n / N jump between hunks
    line-numbers = true
    side-by-side = false    ; set true for two-column diffs
```

## Usage cheatsheet

| Task | Command |
|------|---------|
| Search code | `rg "pattern"` (add `-t py`, `-i`, `-l`) |
| Find files | `fd name` / `fd -e py` |
| View file | `bat file.py` |
| List dir | `eza -l --git` / `eza --tree` |
| Review diff | `git diff` (via delta) |
| Fuzzy pick | `Ctrl-T` (files), `Ctrl-R` (history), `Alt-C` (cd) |
