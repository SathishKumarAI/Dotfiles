# AI Coding

The AI/agent layer for faster, **safer** coding and large-scale project work.
Built around **Claude Code** with a security-conscious config (deny-list, vetted
skills only), automated worklogging, MCP integrations, and a git-worktree
workflow for running multiple agents in parallel.

## Design principles

1. **Safe by default** — a Claude Code deny-list blocks destructive bash
   (`rm`, `git reset --hard`, force-push, package uninstalls). Risky work uses
   `.sh` scripts you run yourself.
2. **Vetted only** — skills/plugins are security-reviewed before install; the
   `caveman` plugin uses the plugin path, never the `curl|bash` one-liner.
3. **Documented** — a Stop hook nudges `/document` so each session lands in
   `docs/WORKLOG.md`.
4. **Parallel + isolated** — large refactors fan out across **git worktrees** so
   agents never clobber each other.
