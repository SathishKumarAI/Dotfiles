## How status was determined

```bash
# Installed binaries
for t in chezmoi mise starship zellij nvim lazygit wofi rofi wezterm tmux \
         zoxide rustdesk fzf rg fd bat eza delta direnv just pre-commit; do
  command -v "$t" >/dev/null && echo "✅ $t" || echo "❌ $t"
done

# Repo vs live divergence
chezmoi status      # M = live differs, A = would add (pending), R = run script
```
