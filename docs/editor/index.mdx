# Editor

| Page | What |
|------|------|
| [neovim](./neovim.mdx) | Terminal editor, Space leader, sensible defaults, git-friendly |
| [vscode](./vscode.mdx) | GUI editor (Flatpak), for heavier IDE work |

neovim is the default `$EDITOR` (used by git, lazygit). VS Code covers GUI-heavy
tasks (extensions, debuggers, notebooks).
